# 高等数学（2-2）复习路线与自测

先学会画积分域和表示约束，再练计算。订正时把错误归到公式条件、几何建模、运算或方向四类，第二天练同方法的另一道题。

| 模块 | 练习顺序 | 自查 |
| --- | --- | --- |
| 多元微分 | 偏导、全微分 → 复合函数与隐函数 → 方向导数、梯度 → 极值 | 方向向量先单位化；用必要条件找候选点后再判断；闭区域别漏边界 |
| 重积分 | 画积分域 → 定上下限 → 换积分次序 → 极坐标、柱面坐标或球坐标 | 换元写雅可比；对常数 1 积分应得到正确的面积或体积 |
| 曲线与曲面积分 | 判断两类积分 → 参数化 → 直接积分或选择积分公式 | 第二类积分先定方向；使用格林、高斯或斯托克斯公式前检查条件 |
| 级数 | 通项 → 正项判别 → 交错与绝对收敛 → 幂级数 | 比值极限为 1 时换方法；求得收敛半径后分别判断两个端点 |

## 自测

1. 在单位圆盘上积分常数 1。用极坐标求得面积为 π，再解释为何面积元里不能省略因子 r。
2. 在圆 $x^2+y^2=1$ 上求 $x+y$ 的最值。用拉格朗日乘子筛出候选，再用柯西不等式验证最值为 $\pm\sqrt{2}$。
3. 对 $\sum_{n=1}^{\infty}x^n/n$，区间内部用比值判别；在左右端点分别得到交错调和级数与调和级数。收敛区间是 $[-1,1)$。
