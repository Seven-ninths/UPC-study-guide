# Java 面向对象程序设计复习

先做输入输出、数组与字符串，再做类的设计和读程序题。最后用文件、集合与线程完成一项综合练习。每道编程题先列典型输入、边界输入和期望输出，再写代码。

## 1. 基础语法与输入输出

- `javac` 将源文件编译为字节码，`java` 启动程序。常见的单文件练习中，文件名要和其中的公开顶层类同名。
- 用 `Scanner` 按整数、单词或整行读取。混用 `nextInt()` 与 `nextLine()` 时，先想清楚当前行尾是否还在输入中。题目按行定义记录时，逐行读入再拆分通常更清楚。
- `5 / 2` 得到整数 `2`，`(double) 5 / 2` 得到 `2.5`。做平均值题先转为浮点数，并明确空输入怎么处理。
- 数组记录长度使用 `length`。遍历不规则二维数组时使用当前行的长度 `a[i].length`。排序后才能用 `Arrays.binarySearch` 做按相同顺序的二分查找。
- 顺着条件追踪每轮更新。遇到 `&&`、`||` 先判断右边是否会执行，再考虑自增、边界和空引用。

自测：`int[] a = {1, 4, 6}; int[] b = a; b[0] = 8;` 后 `a[0]` 为多少？为什么？

## 2. 类、对象与封装

把题目拆成状态、初始化和合法操作。例如借用登记需要设备编号和借用状态，构造器建立初始状态，`borrow()` 决定一次借用是否成功。用私有字段保护状态，使规则集中在方法里。

- 实例字段归各个对象，`static` 字段归类。记录每个对象的编号用实例字段，统计共创建了多少个对象可以用类字段。
- 构造器名称与类名相同，没有返回类型。一旦显式声明了构造器，编译器就不会补一个默认无参构造器。
- `this.field = field` 中左侧是当前对象的字段，右侧是局部参数。静态方法没有当前实例，可以显式接收一个对象再用它调用实例方法。
- Java 按值传递参数。对象参数传入的是引用值的副本。方法可通过此引用改动原来的对象，把参数改指向另一个对象不会改动调用方的变量。
- 重载由参数类型与顺序等决定。只改变返回类型无法构成重载。`equals` 表示何种相等取决于实现，重写 `equals` 时一同维护 `hashCode` 的一致性。

自测：借用第一次应成功，第二次应失败，归还后又可以借用。用两个对象分别测试，确认借用状态彼此独立。

## 3. 继承、重写与多态

做输出题时先写出变量的**声明类型**和 `new` 出来的**实际类**。用声明类型判断方法是否可调用并选择重载，再用实际类确定运行时调用哪一个已重写的实例方法。字段隐藏和静态方法隐藏按声明类型解析。

```java
class Notice {
    String label = "普通";
    String render() { return "站内"; }
}

class Reminder extends Notice {
    String label = "提醒";
    @Override String render() { return "预约即将开始"; }
}

class Preview {
    static String view(Notice notice) { return "通用:" + notice.render(); }
    static String view(Reminder notice) { return "专用:" + notice.render(); }

    public static void main(String[] args) {
        Notice shown = new Reminder();
        System.out.println(shown.label);
        System.out.println(view(shown));
    }
}
```

输出 `普通` 和 `通用:预约即将开始`。字段和重载由 `Notice` 决定，`render()` 的实现来自 `Reminder`。把 `shown` 的声明改为 `Reminder`，再推一遍输出。

设计题中，如果类之间有稳定的“是一种”关系，可以让子类继承共同状态和行为。如果关系是“拥有一个”，可以把另一个对象作为字段。用 `@Override` 检查重写，重写方法的可见范围不能缩小。检查子类构造器最终调用了哪个父类构造器。向下转型前确认实际类型相容。

## 4. 接口、内部类与异常

- 接口适合约定可替换的行为。例如让预约程序接收 `MessageSender`，它只约定 `send(String text)`，测试程序可以传入把消息写入列表的实现。抽象类适合让多个子类复用构造过程、实例状态和具体方法。
- 具体类实现接口的抽象方法时应声明为 `public`。函数式接口的单一抽象方法可以用 Lambda 实现，如 `MessageSender sender = text -> System.out.println(text);`。它可以附带默认方法。
- 成员内部类可访问所属外部实例的状态。静态嵌套类不需要外部实例。匿名类适合一次性实现并可声明自己的成员。对比它和 Lambda 中 `this` 指向的对象。
- `throw` 抛出异常对象，`throws` 声明方法可能传播异常。受检异常需要处理或声明传播。多个 `catch` 按更具体的异常类型在前安排。读取文件时用 `try` 带资源语句确保关闭流。

自测：给预约程序增加一个返回成功与否的发送器，分别用正常、空消息及模拟发送失败验证调用方的处理。

## 5. 字符串、文件、集合与线程

| 问题 | 判断方法 |
| --- | --- |
| 判断字符串内容或提取片段 | 用 `equals` 比较内容。截取区间通常是左闭右开。明确用正则还是按字面量匹配。 |
| 用正则校验或搜索 | `matches()` 要求整个输入匹配，`find()` 找下一段匹配。Java 字符串里的正则反斜杠要再转义。 |
| 时间计算 | 纯日期用 `LocalDate`，需要日期和当天时间时再用 `LocalDateTime`。测试跨月、闰年及日期边界。 |
| 选择读文件方式 | 文本按字符和编码处理。逐行处理可用缓冲字符流。二进制内容按字节读取。先判断是否到达文件末尾。 |
| 选择集合 | 需要顺序和可重复元素用 `List`。需要去重用 `Set`。需要键值映射用 `Map`。输出按键排序时可用 `TreeMap`。 |
| 线程启动与结果 | `start()` 启动新线程。直接调用 `run()` 在当前线程执行。需要主线程等待工作结束时用 `join()`。 |

综合练习：读一个 UTF-8 文本文件，每行格式为 `2026-04-02,A12,borrow`。跳过空行，报告坏记录行号，找出每个设备的借用次数，并按设备编号升序输出。用空文件、含坏日期、重复设备、同一设备同时出现 `borrow` 与 `return` 的数据验证。把解析、统计和输出拆成三个方法，便于单独测试。

前四部分自测中，`a[0]` 为 `8`，因为 `a` 和 `b` 引用同一个数组。继承例题改用 `Reminder` 声明后，输出 `提醒` 和 `专用:预约即将开始`。
