# 大学物理复习路线与自测

先画受力、光路或场的示意图，再选坐标系列式。完成后检查单位、方向和极限情况。

| 模块 | 练习顺序 | 自查 |
| --- | --- | --- |
| 质点与质点系 | 运动描述 → 牛顿定律 → 动量、能量、角动量 | 画清系统边界；对每个守恒量单独说明条件 |
| 振动与波动 | 初始条件 → 振幅与相位 → 行波、叠加与驻波 | 追踪等相位点判断传播方向；区分波速和质点速度 |
| 波动光学 | 光程差 → 干涉 → 衍射与偏振 | 先区分光程与几何路程，检查反射相位变化 |
| 热学 | 理想气体状态量 → 准静态过程 → 第一定律与循环 | 明确功的正负约定；用 $p$–$V$ 图的面积核对功 |
| 静电学 | 电荷分布 → 场强叠加或高斯定律 → 电势 → 导体与电介质 | 用高斯定律求场强之前先检查场的对称性 |
| 稳恒磁场与电磁感应 | 场的计算 → 磁场力 → 法拉第定律与楞次定律 | 先定环路和法向；检查感应效应是否反抗磁通量的变化 |

1. 将正点电荷从球面中心移到球内的偏心位置。球面的电通量仍为 $q/\varepsilon_0$，但场强不再处处等大且沿半径，不能直接用通量除以面积求每点场强。
2. 垂直纸面向里的磁场增强时，纸面内圆线圈的感应电流从观察者视角为逆时针，它在中心产生朝纸面外的磁场。
