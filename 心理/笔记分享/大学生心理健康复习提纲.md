# 大学生心理健康复习提纲

| 主题 | 课后练习 |
| --- | --- |
| 心理健康与自我认识 | 用学习、情绪、人际和适应四个方面描述同一个情境，区分观察得到的事实与自己作出的判断。 |
| 意识与睡眠 | 画出睡眠中非快速眼动和快速眼动阶段交替出现的大致过程。 |
| 情绪识别与表达 | 记下一次具体事件，分别写下感受、身体反应、当时的解释和随后采取的行动。 |
| 人际关系与沟通 | 为宿舍作息冲突设计两轮对话。先复述对方关心的问题，再表明自己的需求，并一起约定可执行的调整。 |
| 求助与心理咨询 | 根据课程资料列出学校的求助渠道，以及咨询前可以准备的信息。预约方式以学校当前通知为准。 |

复习“人格、气质、性格、自我意识”时，用同一个案例解释各概念分别描述了什么。复习人际效应时，试着为自己的第一印象找一个可以检验的解释，并找出可能反驳它的事实。遇到问卷、案例和课堂讨论题，可以回到课程提供的正式入口学习。
