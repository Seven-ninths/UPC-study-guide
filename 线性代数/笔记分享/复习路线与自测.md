# 线性代数复习路线与自测

以高斯消元串起行列式、矩阵的秩和线性方程组。每次做行变换前，想清楚操作保持什么；例如行交换保持秩但会改变行列式的符号。

| 模块 | 必练 | 易错点 |
| --- | --- | --- |
| 行列式、矩阵与逆 | 化上三角求行列式；用增广矩阵求逆 | 矩阵乘法一般不可交换；行列式要记录交换行与缩放行 |
| 秩、方程组与向量组 | 比系数矩阵和增广矩阵的秩；从主元与自由变量写通解 | 非齐次通解是特解加齐次通解；选列空间基要取原矩阵的主元列 |
| 特征值与相似 | 求特征多项式；对各特征值解齐次方程；组装相似变换 | 重根对应的特征向量可能不够；特征向量的列顺序须与对角线顺序对应 |
| 正交性与二次型 | 正交化和单位化；对实对称矩阵作正交对角化 | 交叉项系数由两个对称的非对角元素共同给出；相似与合同各有不同的不变量 |

1. 对矩阵 $A=\begin{pmatrix}1&2&3\\2&4&6\end{pmatrix}$，分别取 $b=(5,10)^T$ 和 $b=(5,9)^T$ 解 $Ax=b$。前者有两个自由变量；后者消元后出现矛盾行。
2. 矩阵 $\begin{pmatrix}2&1\\0&2\end{pmatrix}$ 的特征值 2 为重根，但特征空间只有一维，因此无法对角化。
