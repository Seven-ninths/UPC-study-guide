# 通用英语（2-2）B 层次复习提纲

本地范围说明适用于 2025–2026 学年第二学期的 2025 级 B 层次。读写教程为《新视野大学英语读写教程》第四版第 3 册 Unit 1–5，Unit 5 只复习 Section A。视听说教程为第四版第 3 册 Unit 1–5。其他学期以任课教师当学期通知为准。

| 复习模块 | 练习方式 |
| --- | --- |
| 听力 | 短新闻、长对话和篇章各练一组。只听一遍，记下人物、行动和转折，核对自己遗漏了哪条信息。 |
| 课外阅读 | 选词时先判断空格所需词性，再看搭配与句意。信息匹配找同义改写和定位词，仔细阅读从原文找证据。 |
| 教材词汇 | 按单元整理高频词的词性、搭配、近义区别和自己造的例句。 |
| 同义转述与课文理解 | 为每篇课文写一句段落主旨，练习在保留语气和因果关系的前提下换一种说法。 |
| 阅读与写作技能 | 选择一段议论文，分别标出主张、例证、让步和结论。 |
